# AYN Thor setup transfer

[Download the complete setup ZIP](https://github.com/NavrajBal/ayn-thor-setup/releases/download/transfer-2026-11-06/Thor-Complete-Setup.zip)

[Release page](https://github.com/NavrajBal/ayn-thor-setup/releases/tag/transfer-2026-11-06)

1. Download Thor-Complete-Setup.zip on the Thor (about 678 MB).
2. Extract it using the Files app.
3. Open START-HERE.md in the extracted Thor-Setup folder.
4. Copy ROMs to internal storage or the installed microSD card; merge with care if a library already exists.
5. Install only the apps that are missing. Android permissions and controller mappings still need to be configured on the device.
6. Read RESUME-UNBOUND.md to import the existing playthrough into RetroArch/mGBA before starting it.

The ZIP contains 466 game folders/checklists, nine Android installers, and the owner's existing Unbound ROM/save and matching base ROM. Most game folders are placeholders. No BIOS is included.

This is a temporary personal transfer repository. It will be made private after download confirmation.
